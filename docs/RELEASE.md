# sogo-FC5-v1.0.1

- 源码版本：`1.0.1`。
- 目标环境：Ubuntu 24.04 amd64、X11、Fcitx5 5.1.7。
- 公开资产：源码归档、构建工具、SHA-256 校验文件。
- 搜狗闭源引擎、词库、官方安装包和本地组装 deb 不属于公开 Release 资产。
- 学习保存：提交后空闲约 2 秒或持续输入约 30 秒时尝试保存，正常退出执行原厂同步保存；`sogo-fc5-direct-status --learning` 提供无输入内容的保存诊断。
- 升级后需要注销并重新登录，确保 Fcitx5 模块与工作进程使用通信协议版本 3。
- 本地构建需自行取得 `vendor/baseline.json` 对应的官方包并核对适用许可。
- 自动检查范围：17 项非桌面测试、固定原厂库哈希、包结构、依赖和重定位；详细技术范围见 `verification.json`。
- 桌面输入、小键盘数字混排、主题实际呈现和学习写回仍需实际桌面验证。

源码归档不包含本地依赖或构建产物。与发布资产同名的 `.sha256` 文件用于校验归档完整性，不代表厂商签名或授权。构建与安装见根目录 README，第三方权利说明见 `NOTICE.md`。
