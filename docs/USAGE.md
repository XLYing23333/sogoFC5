# Sogo-FC5

面向 Ubuntu 24.04 amd64、X11、Fcitx5 5.1.7 的官方搜狗 FC4 引擎适配。
版本 `1.0.0`，使用官方 `sogoupinyin 4.2.1.145` 的引擎和词库。

原生 Fcitx5 模块与独立引擎调用端提供按键、候选和状态管理；真实搜狗转换、学习数据写回和桌面稳定性仍需桌面验证。
静态 ABI 校验和模拟上下文测试通过不代表真实中文输入已经验收。

## 运行结构

- Fcitx5 原生模块管理按键、焦点、提交、预编辑和候选列表。
- 单个独立进程直接调用 `GetSogouShell` 返回对象，使用桌面拼音布局 `19`。
- 不运行 FC4 主程序、原厂 FC4 插件、搜狗面板、原厂设置程序或 CPIS。
- 每个请求原子返回处理结果、提交、预编辑和候选状态；按上下文、代次、序号校验后应用。
- 每个操作开始前清理内部提交缓冲与 UTF-8 结果副本，保留局部选词后的剩余拼音。不同选词操作可连续提交相同文本，不按内容去重。
- 按下与松开均保留顺序；PC Shell 使用虚拟键码，按下设置 `0x80000000`，松开清除该位。
- Shift/Ctrl 单键不送入引擎。普通字母的修饰状态写入原厂事件状态表，Ctrl/Alt/Super 等应用快捷键保留原始前端事件。
- 从请求入队起采用 180 ms 截止时间，给事件循环调度预留 20 ms。失败时取消组词、按序回放未确认按键并切回英文；恢复后的中文启用由用户执行。

这不是硬实时保证；调度、桌面前端和应用自身仍可能阻塞。
原厂二进制仍然闭源；本工程提供的是经静态调用点核对的 C++ 接口与新的 Fcitx5 实现，不是完整恢复的搜狗原始源码。

## 安装与首次启用

```sh
sudo apt install /path/to/sogo-FC5-v1.0.0_amd64.deb
```

安装不修改 Fcitx5 用户分组、不切换输入法、不重启当前进程。
升级会替换本包提供的旧文件；已加载的旧模块在当前会话结束前仍可能保留在内存中。
升级后需要注销并重新登录，使 Fcitx5 模块与工作进程使用相同的通信协议版本。

在首次添加本输入法前，可以手动执行独立引擎探针：

```sh
timeout 15s /usr/lib/sogo-fc5-direct/sogo-fc5-direct-engine --probe
```

探针会使用固定的 `nihao` 输入检查候选和提交，不向桌面应用注入按键。
返回 JSON 中 `nihao_candidate` 和 `nihao_commit` 应均为 `true`，退出码应为零。
本包开发检查未运行该探针。已经运行中的 Sogo-FC5 引擎会持有用户词库锁，此时探针会拒绝重复打开同一份数据。

完成探针后注销并重新登录，在 Fcitx5 配置中添加：

**Sogo-FC5**

输入法分组中保留英文键盘和已有 Rime 作为对照。
首次选择时引擎需要初始化；等待完成后再次切入中文。
`Ctrl+Space` 等框架切换键由 Fcitx5 全局配置管理，模块不会覆盖该配置。
若仍配置了 Shift 切换输入法，需要在 Fcitx5 全局设置中移除；该按键会先于输入法模块处理。

## 外观

提供 `Dark Mode` 和 `WeLight Mode` 两套 Classic UI 主题，目录分别为：

- `/usr/share/fcitx5/themes/sogo-direct-dark-mode`
- `/usr/share/fcitx5/themes/sogo-direct-welight-mode`

输入法菜单中的 `Dark Mode / WeLight Mode` 手动切换深浅配色；切换时将 Classic UI 的 `UseDarkTheme` 设为 `False`。
这些操作只调用 Classic UI 配置接口，不发送引擎重置、焦点切换或输入法切换命令。
Classic UI 的外观设置是全局设置，也会影响使用该界面的其他输入法。
字体沿用现有 Fcitx5 设置；未安装时不会改写字体。

候选窗位置、屏幕边界、DPI、分页按钮布局均交给 Fcitx5；本包不绘制原厂浮动栏。
原厂属性设置程序和激活入口不随包安装。
候选高亮独立于字体和行间距：深色高亮左右外扩 6、上下外扩 5 个逻辑像素；浅色四边外扩 3 个逻辑像素。

预编辑文本、游标或候选页变化时才更新对应界面；内容相同的松键回复不重建候选列表、不重复通知应用。
提交文本仍逐条处理，不合并不同按键或选词操作；提交后重新通知剩余预编辑，避免客户端清掉组词显示。
缓存随输入上下文、重置、焦点和故障清理失效。
socket 可读事件直接处理引擎回复，空闲巡检每秒一次；有未完成请求时，定时器按最早请求的截止时间提前唤醒。
状态发布使用独立的绝对巡检时刻，持续输入不会一直推迟状态记录。

## 候选与编辑按键

候选已有与位置对应的数字编号时，Fcitx5 不再额外添加该编号；原始候选内容和按位置选择的行为保持一致。

有候选时，`-` 和 `PageUp` 向前翻页，`=` 和 `PageDown` 向后翻页。
翻页在引擎进程中按最新组词状态决定，不依赖原厂快捷键配置；页码和按钮状态在收到成功回复后更新。
PC Shell 的翻页返回值不区分边界，适配端比较翻页前后的候选内容确认可见页面变化；完全相同的候选页不能据此区分。
没有组词时，`-`、`=` 保持普通符号输入；Shift 配合输入的 `_`、`+` 不用于翻页。

长按 Backspace 使用桌面前端产生的重复按键，不启动额外重复计时器。
有组词时每次重复删除一次，并在原厂引擎内配对按下与松开；组词删空后，后续重复交还应用删除正文。
转发事件不携带 Fcitx5 内部的 Repeat 标志。不会用删除周围文本或模拟全局按键代替应用的编辑操作。

组词期间，小键盘 `KP_0` 至 `KP_9` 使用独立的 `VK_NUMPAD0` 至 `VK_NUMPAD9` 送入搜狗，区别于主键区的候选序号键。
运行时通过原生环境接口关闭 `PadNumAsSelect`，关闭已有配置中可能开启的小键盘选词；新配置也以关闭值初始化。
已解析为数字的 X11 keysym 在原生字符转换时固定数字锁定状态，按物理键配对处理 NumLock 改变后的松键。
无组词时小键盘数字、NumLock 关闭后的导航键，以及 Ctrl/Alt/Super 组合键继续由应用处理。
字母与数字混排的转换、候选及最终提交结果仍需真实引擎和桌面验证；模拟测试只覆盖路由、虚拟键及预编辑结果传递。

## 数据与恢复

私有数据根目录为 `${XDG_DATA_HOME:-$HOME/.local/share}/sogo-fc5-direct`。
原厂进程使用其中的 `home/.config/sogoupinyin` 保存配置和学习数据。
数据目录权限为 0700，新配置为 0600；词库锁防止两个实例并发写入。
初始配置禁用原厂单键切换、辅助快捷键和自动补齐括号；括号使用手动闭合。
安装不整份替换已存在的配置或学习文件，卸载不删除用户目录。
小键盘选词策略在引擎启动后由原生 `t_env` 设置；原厂正常保存配置时可能写回该单项，其他配置与学习内容不整份替换。

`~/.local/share/sogo-fc5` 中的 NG/CPIS 数据和传统 `~/.config/sogoupinyin` 数据不会被自动转换或删除。
本包使用独立词库，未实现不同引擎版本间的学习数据迁移。
正常退出调用原厂释放流程；强制终止可能丢失尚未刷写的学习结果，实际保存行为尚待验证。

故障后先切回英文或 Rime；后台引擎重建后按既有切换键重新选择 Sogo-FC5。
卸载：

```sh
sudo apt remove sogo-fc5
```

## 诊断

```sh
sogo-fc5-direct-status > direct-status.json
```

状态记录位于 `${XDG_RUNTIME_DIR}/sogo-fc5-direct/status.json`，包含就绪状态、引擎 PID、请求计数、平均/最大耗时、转发计数与故障原因。
本包诊断不记录按键内容、拼音、候选或提交文本；原厂学习数据不属于诊断记录。

耗时均为微秒，统计从当前 Fcitx5 模块启动起累计：

| 字段 | 范围 |
| --- | --- |
| `mean_engine_us`、`max_engine_us` | 独立进程内的引擎处理与状态读取 |
| `mean_delivery_us` | 请求入队至收到匹配回复，包含排队与通信 |
| `mean_total_us`、`max_total_us` | 请求入队至结果应用结束，包含解码及同步界面通知 |
| `mean_present_us`、`max_present_us` | 提交、预编辑和候选更新的同步调用 |
| `p95_total_us_upper`、`p99_total_us_upper`、`p95_engine_us_upper` | 固定直方图估算的百分位上界，不是精确百分位 |
| `ui_updates`、`preedit_updates`、`candidate_updates` | 实际发起的对应更新次数 |
| `timer_wakeups` | 定时巡检/超时检查的唤醒次数，不含 socket 唤醒 |

上述计时不覆盖按键到达模块前的前端延迟，也不等待应用或合成器完成异步绘制。
应结合最大值、百分位上界和 UI 更新次数判断抖动；仅看平均值不能排除短暂卡顿。

安装验证应分别记录：终端连续中文、Ctrl+Shift+C/V、Shift 大写、括号、候选翻页、窗口切换、深浅主题切换。
主动暂停或终止进程时，只操作状态记录中属于本包的引擎 PID，不操作 Fcitx5 主进程。
强制终止后的恢复、200 ms 时限和真实长时间性能均需桌面验证。

## 构建

依赖 CMake、Ninja、G++、Python 3、GNU binutils、dpkg-dev、Qt5 Core 开发库和 Fcitx5 Core/Config/Utils 开发库。
protobuf 编译器与开发库可用于额外检查恢复的协议源码；运行时不依赖 protobuf 或 Python。

```sh
sh scripts/build-deb.sh /path/to/sogoupinyin_4.2.1.145_amd64.deb /path/to/output.deb
```

可选第三个参数指定解包的 Noble Fcitx5 SDK 根目录。
输入包和关键 ELF 的哈希固定在 `vendor/baseline.json`。
构建会解包、编译、运行非桌面检查并组装 deb，不执行上游维护脚本，不安装依赖或成品，不连接桌面。
包检查只在哈希检查模式下执行新引擎程序，并用动态加载器的依赖跟踪模式检查链接，不加载运行原厂引擎。
检查也覆盖完整依赖组的 `ldd -r` 重定位。兼容导出保留标准异常语义，并拒绝原厂窗口构造；若纯引擎路径实际依赖原厂窗口，该版本会失败降级，详见 `ABI.md`。

## 自动检查范围

| 检查 | 覆盖范围 |
| --- | --- |
| `compiler-abi-contract` | 编译器产生的虚函数表与借用字符串复制，使用模拟对象 |
| `descriptor-decoder` | 原厂描述信息提取、损坏输入拒绝及协议源码重生成 |
| `native-runtime-guards` | 标准异常兼容语义、原厂窗口构造拒绝及注入/抓键接口禁用，使用本包函数 |
| `native-keys` | 虚拟键映射、按下/松开标志、修饰状态与终端快捷键路由 |
| `native-queue` | 请求顺序、容量、截止时间、上下文代次和原子结果编解码 |
| `native-editing` | 模拟引擎的前后翻页、边界和按键松开、Backspace 重复与组词删空、已提交结果不重复返回 |
| `native-result_buffers` | 双层结果缓冲的重复提交复现；局部选词、剩余拼音、后续快速输入、松键、翻页、删除、重复选择相同文本和上下文重置，使用模拟引擎 |
| `native-transport` | Unix socketpair、损坏消息、暂停/终止的模拟子进程及断连；不运行原厂代码 |
| `native-profile` | 私有目录、单一配置文件、升级保留数据和词库锁 |
| `native-presentation` | 无桌面前端的 Fcitx5 InputContext 模拟对象，提交、预编辑、候选和翻页 |
| `native-scheduling` | 空闲巡检、最老请求截止时间、启动与重试调度，以及独立 Fcitx 事件循环中的单次超时唤醒 |
| `native-latency` | 耗时累计、最大值、直方图百分位上界和溢出区间 |
| `native-keypad` | 小键盘与主键区数字分离、组词续输、删除、NumLock 松键配对、焦点清理和应用快捷键，使用模拟引擎 |
| `recovered-protocol-source` | 恢复的 proto2 源码经 protoc 生成 C++ 后编译和编解码检查 |
| `official-binary-static-contract` | 固定 ELF、虚函数表、PC 键盘约定和协议字段的静态校验 |

原厂真实转换、桌面输入顺序、学习写回、应用兼容性和候选窗实际外观不在上述已验证范围。
第三方引擎及词库权利归各自权利人；包内保留原厂许可文件。

界面同步开销可单独使用构建目录中的 `presentation-benchmark` 检查。
该工具对比无条件更新与变化缓存，执行 7 轮固定模拟序列，每轮 120000 个事件，并核对提交数量。
它没有真实前端、搜狗转换或屏幕绘制；结果不能当作桌面端到端性能结论。
